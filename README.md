Bluetooth Chat App 📱

An offline Bluetooth messaging application developed using Kotlin and Android Studio.

Features

- 📡 Bluetooth communication
- 💬 Send and receive text messages
- 🟢 Sender messages aligned to the right
- ⚪ Receiver messages aligned to the left
- 💭 Chat bubble UI
- 🕐 Message time
- ✔✔ Double message ticks
- 🔵 Blue read ticks
- 📱 Android application

Technologies

- Kotlin
- Android Studio
- Android SDK
- Bluetooth
- RecyclerView
- XML

How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle.
4. Connect an Android phone.
5. Enable Bluetooth and required permissions.
6. Build and run the application.
